# AdForge AI

A static, client-side creative testing workflow for Shopify beauty and skincare brands.

## Flow
Product Brief → Creative Angles → 30-Creative Sprint → Testing → Iteration → QA

## Privacy
The dashboard stores its brief and angle selections in the browser's localStorage. No backend or API key is required.
